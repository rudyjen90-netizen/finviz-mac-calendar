股市日历隐私权政策

生效日期：2026年11月25日。适用于本个人股市日历同步工具。

访问的数据与用途

经用户明确授权，程序通过 Google Calendar API 访问主日历近期事件的时间、标题、描述和标识符，以识别重复行情记录；创建或更新股市行情事件并验证结果。Google 日历权限允许访问其他事件，但程序仅按行情标识匹配和更新目标记录。公开市场行情来自第三方行情来源，不是 Google 用户数据。

存储与传输

OAuth 授权凭据预定由账户持有人保存在 GitHub Actions 加密 Secrets 中。工作流在 GitHub 托管运行环境执行，与 Google API 通信。同步程序不将读取到的个人日历事件写入公开网页或行情文件，也不主动将其内容输出至运行日志。公开网页和 ICS 文件仅包含公开市场数据。GitHub 和 Google 分别按其服务政策处理平台数据。

数据使用限制

Google 用户数据仅用于用户授权的日历同步功能。不出售用户数据、不用于广告、不用于训练通用 AI 模型，不向无关第三方提供个人日历内容。对 Google API 所获信息的使用及转移遵守 Google API Services User Data Policy，包括 Limited Use 要求。

保留、撤销及删除

程序不建立个人日历内容的独立持久数据库。用户可在 Google 账户第三方连接设置 撤销访问，并在 GitHub 仓库设置删除授权 Secret、停用工作流。已创建的行情事件可在 Google 日历删除。

联系方式

通过 项目问题反馈页面 联系维护者；请勿在公开问题中提交凭据或私人日历内容。
